# Explain Simply

> Get a layered explanation, from one sentence to real depth.

**Variables:** `{{topic}}`

## When to use
Quickly understanding a concept before going deeper.

## Prompt
```text
Explain {{topic}} in three layers:
1. One sentence a 12-year-old would understand.
2. One paragraph for a smart non-expert, with an everyday analogy. Say where the analogy breaks down.
3. A technical explanation for a practitioner, including common misconceptions.

End with three questions I should be able to answer if I truly understand it.
```
